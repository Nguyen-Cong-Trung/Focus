Spertulo Utility

GET STARTED
1. Extract this entire folder to a location you want to keep.
2. Double-click Focus.exe. Python installation is not required.
3. Optional: run Create Desktop Shortcut.cmd to create a shortcut.

Keep the _internal folder beside Focus.exe. Do not run inside the ZIP.

SOUNDS AND CLOSING
Closing the window stops all sounds. If Keep working in the tray is enabled,
the timer continues in the notification area. Use Stop all sounds in Sound
Studio or the tray menu. Use Quit Focus in the tray menu to exit completely.
Launching Focus again reopens the existing instance.

YOUR DATA
Your workspace is stored in %USERPROFILE%\.deepfocus, separate from this folder.
Use Settings to back up or restore your workspace. Updating the app does not
require deleting this data. No personal workspace is included in this download.

WINDOWS PERMISSIONS
Website blocking may require running Focus as administrator.
Shutdown Timer only schedules shutdown after you explicitly confirm it.
